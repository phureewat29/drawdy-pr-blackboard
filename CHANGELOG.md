# Changelog

## 1.0.0

First release.

- Pin any public GitHub PR to your Drawdy board: each changed function
  becomes a card, joined to the code it calls, its callers and its tests by
  labelled strings.
- Step through the code card by card from the panel, click a name to jump
  along its string, or press Overview to see the whole board.
- Strings for TypeScript, JavaScript, Python, Go and Rust, drawn only where
  the parser can prove the link.
- 15 example PRs to try, from Hono, Vite, Node.js, Svelte, Bun, Prometheus,
  CPython and more.
- Read only: no account, no sign-in, and nothing is changed on GitHub.
